# استقرار در هاست Node.js چابکان

نسخهٔ جدید با Node.js معمولی اجرا می‌شود. به Next.js، پوشهٔ runtime، مرحلهٔ build، PM2 یا Nginx جداگانه نیاز ندارد. تنها وابستگی Sharp هنگام نصب روی خود هاست دریافت می‌شود.

## ۱. تهیه و بارگذاری فایل‌ها

روی رایانه، در پوشهٔ `site`:

```sh
npm run package:host
```

فایل `dist/sinakratos-chabokan.tar.gz` را بارگذاری کنید و محتوای آن را در ریشهٔ برنامه، معمولاً `/app`، استخراج کنید. ساختار صحیح:

```text
/app/package.json
/app/package-lock.json
/app/server.mjs
/app/server/
/app/public/
/app/scripts/
```

اگر نسخهٔ قبلی فعال است، ابتدا سرویس را متوقف و از پایگاه داده و تنظیمات خصوصی پشتیبان تهیه کنید. فایل‌های برنامهٔ قدیمی را با این بسته جایگزین کنید؛ پوشهٔ دائمی `data` و تنظیمات خود را نگه دارید. اجرای برنامهٔ نمونهٔ index.js یا start.cjs نسخهٔ قبلی باید با دستور زیر جایگزین شود.

## ۲. تنظیم سرویس

نسخهٔ Node.js را **24** انتخاب کنید. تنظیمات:

| تنظیم | مقدار |
|---|---|
| Install command / NPM_INSTALL_COMMAND | `npm ci --omit=dev` |
| Start command / START_COMMAND | `npm start` |
| Build command | خالی؛ برنامه به build نیاز ندارد |
| PORT | `3000` |
| APP_HOST | `0.0.0.0` |
| ADMIN_PASSWORD | گذرواژهٔ شخصی، حداقل ۱۶ نویسه |
| SESSION_SECRET | رشتهٔ تصادفی خصوصی، حداقل ۳۲ نویسه |
| DATABASE_PATH | `/app/data/resume.sqlite` |
| PUBLIC_ORIGIN | `https://sinakratos.ir` |

مقدار قدیمی NPM_INSTALL_COMMAND که نصب را غیرفعال می‌کرد حذف کنید. این نسخه باید وابستگی خود را روی هاست نصب کند. `npm run build` را نیز از دستورهای قبلی حذف کنید.

برای تولید SESSION_SECRET می‌توانید روی رایانه اجرا کنید:

```sh
openssl rand -hex 32
```

برای بررسی با دامنهٔ آزمایشی، PUBLIC_ORIGIN را موقتاً روی همان آدرس HTTPS تنظیم کنید؛ پس از اتصال دامنه مقدار نهایی را وارد و سرویس را مجدداً راه‌اندازی کنید. برنامه را از بخش Restart/Redeploy پنل اجرا کنید. در کنسول یک نمونهٔ دوم با npm start اجرا نکنید؛ پورت ۳۰۰۰ متعلق به نمونهٔ فعال سرویس است.

فایل `.env.local` رایانه در بسته قرار نمی‌گیرد. تنظیم متغیرها در پنل توصیه می‌شود؛ در صورت نیاز، برنامه فایل `/app/.env.local` را هم می‌خواند. متغیرهای پنل اولویت دارند. برای بررسی بدون نمایش گذرواژه:

```sh
cd /app
npm run check:env
```

## ۳. حفظ اطلاعات

مسیر `/app/data` را در پنل به‌عنوان مسیر دائمی تعریف کنید. پایگاه داده شامل اطلاعات رزومه و تصاویر است. قالب قبلی SQLite مستقیماً پشتیبانی می‌شود. اگر اطلاعات قبلی در مسیر دیگری بوده است، DATABASE_PATH را به همان فایل تنظیم کنید یا فایل را هنگام توقف سرویس به مسیر جدید منتقل کنید. بستهٔ بارگذاری اطلاعات محلی شما را شامل نمی‌شود.

## ۴. اتصال دامنه

در بخش دامنه‌های سرویس، `sinakratos.ir` را اضافه کنید، رکوردهای DNS اعلام‌شده توسط چابکان را در مدیریت دامنه قرار دهید و HTTPS را فعال کنید. IP ترافیک خروجی سرویس لزوماً مقصد DNS نیست. در صورت افزودن `www` بهتر است آن را به دامنهٔ اصلی هدایت کنید.

پس از اجرا، ورود به `/admin`، ذخیرهٔ یک تغییر و بارگذاری تصویر را بررسی کنید. سپس یک بار راه‌اندازی مجدد انجام دهید و ماندگاری اطلاعات را کنترل کنید. مصرف حافظه به درخواست‌ها و پردازش تصویر وابسته است؛ محدودیت واقعی را در نمودار سرویس بررسی کنید.
